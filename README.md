#Sistema de Agendamento de Consultas-Especificaçaõ de Requisitos 
##1; Visão Geral
Este documento especifica os requisitos funcionais e não funcionais do módulo de agendamento.

## 2. Requisitos Funcionia (RF)
-{ } RF01: o paciente deve conseguir visualizar os horários de cada médico.
-{ }RF02: o sistema deve permitir o agendamento de cosnltas com confirmação por email
-{ }RF03: O médico deve visualiza sua agenda diãria e semanal.

## 3. Requisitos Não Funcionais (RNF)
-RNF01 (Desempenho): O tempo de resposta para busca de horários não deve exceder 2 segundos.
-RNF02 (Segurança): Dados sensiveis de saúde deve estar em conformidade com a LGPD.
